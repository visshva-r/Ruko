# Copy-paste for Unstop project description

**Title:** RUKO — Family Scam Checker (Digital Safety)

**One-liner:** Paste or upload a suspicious message; get Stop/Caution/Safe with proof, a safe action, and Hindi/English replies.

**Problem:** Family impersonation and UPI/OTP scams on WhatsApp and SMS cause fast, irreversible losses — especially for users who are not security experts.

**Solution:** RUKO combines a deterministic Indian scam signal engine (UPI handles, OTP asks, “don't call”, urgency, short links) with Gemini for screenshot reading and contextual verdicts. Evidence is shown on the original text so users see *why*, not just a label.

**Tech:** Next.js, TypeScript, Tailwind, Gemini API, Web Speech API.

**Demo:** Use built-in case “Son — new number, don't call” then “Safe — real family check-in”.

**Theme:** Digital Safety & Cybersecurity.
